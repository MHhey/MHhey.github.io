Property listing and booking platform

Web application for student housing management, with authentication, property listings and a booking system with real-time updates. Delivered by a six-person team over two semesters.

RoleProject lead and full-stack developer
StackReact · Node.js · PostgreSQL · Jira
WhenMay — December 2025

Overview

Listing and booking for off-campus student housing were spread across channels that lose state: scattered listings, stale availability, no reliable record of bookings. The platform consolidates listing, search and booking into one system so property state is consistent for every user.

Stack

  • Frontend — React
  • Backend — Node.js
  • Database — PostgreSQL
  • Process — Jira, agile, two-semester delivery

Features

  • User authentication
  • Property listings with search
  • Booking system with real-time availability updates

My role

  • Project management for a six-person cross-functional team: stakeholder requirements, sprint planning, coordination
  • PostgreSQL schema for listings, users and bookings
  • Implementation of authentication, listings interface and booking flow

Notes

  • Real-time booking is a concurrency problem, not a frontend feature. Two users opening the same listing simultaneously must be resolved in the database, not the UI. Setting that boundary early avoided a class of bug that is expensive to fix later.
