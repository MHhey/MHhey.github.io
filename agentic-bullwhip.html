Agentic AI simulation of construction supply chains

Modeled five supply chain tiers as autonomous AI agents ordering from limited local information, and measured how far shared information reduces the distortion that reaches suppliers.

RoleLead author: design, implementation, analysis
StackPython · AutoGen · crewAI
StatusUnder review, 2025

Overview

The bullwhip effect describes order variance growing as it moves upstream through a supply chain: a small change on site becomes a large one for the fabricator, and larger still for the supplier. Construction has the same tiered structure as manufacturing but weaker information flow: each tier generally sees only its immediate neighbours, so it orders defensively against uncertainty it cannot resolve.

Classical bullwhip models assume rational agents optimising a known cost function over information they do not have in practice. This project replaces that with autonomous LLM agents reasoning in natural language over the information each tier actually holds.

System configuration

  • Orchestration: AutoGen
  • Agent role definition: crewAI
  • Simulation core: Python; deterministic inventory accounting and order settlement
  • Agents: 5 tiers: supplier, fabricator, subcontractor, contractor, owner
  • Agent state: role prompt, inventory level, order history, visibility window

Information regimes

  1. Open-loop: agents observe only their own orders and receipts. Baseline; matches current practice in most construction supply chains.
  2. Closed-loop: downstream demand and upstream lead-time signals shared across tiers.

No agent receives the global demand signal in either regime.

Execution loop

for period in horizon:
    for tier in chain:                  # downstream → upstream
        context = tier.observe()        # regime-dependent visibility
        order   = tier.decide(context)  # LLM agent
    simulator.settle(orders)            # deterministic accounting
    record(variance, inventory, stockouts)

Metrics

  • Order variance amplification between adjacent tiers
  • Inventory swing and stockout frequency per tier
  • Propagation time for a demand shock to reach the top of the chain
  • Divergence between agent decisions and human decisions in the same scenario

Method notes

  • Inventory accounting sits outside the agents. Agents decide; the simulator settles. Keeping arithmetic out of the model prevents its errors contaminating the measured variance.
  • Runs repeat across seeds. Agent decisions are non-deterministic, so results are reported as distributions rather than single traces.
  • Agent prompts are versioned with results, since a prompt change is a change to the experimental condition.
