Agentic AI simulation of construction supply chains

Modeled a five-tier construction supply chain as autonomous LLM agents, each ordering from only what it can see, and measured how a small change on site grows into large swings upstream — and what actually reduces it.

RoleLead author: design, implementation, analysis
StackPython · OpenAI GPT-4o-mini
StatusUnder review, 2025
CodeGitHub repository

Overview

The bullwhip effect is when order variance grows as it travels upstream: a small change on site becomes a larger one for the distributor, and larger still for the supplier. Construction has the same tiered structure as manufacturing but weaker information flow — work is organised into temporary project coalitions, and each tier usually sees only its immediate neighbours, so it orders defensively against uncertainty it cannot resolve.

Traditional agent-based models encode each tier's behaviour as a fixed ordering rule. This study replaces those rules with autonomous LLM agents that reason over the information each tier actually holds and return a structured ordering decision, so behaviour adapts to context rather than following a preset heuristic.

How it is built

Five agents represent the tiers of a construction supply chain — Contractor, Procurement Office, Third-Party Logistics (3PL), Distributor, and Supplier. Each agent holds its own inventory, backlog, and in-transit state. On every time step an agent reads the slice of the system it is allowed to see, calls an LLM to decide how to order, and the simulator settles the resulting material and information flow deterministically before the next step.

  • Agents — 5 tiers: Contractor, Procurement Office, 3PL, Distributor, Supplier.
  • Decision model — OpenAI GPT-4o-mini, low temperature, returning a schema-constrained JSON vector of ordering coefficients.
  • Simulation core — Python; deterministic inventory accounting, order settlement, and lead times.
  • Agent state — role prompt, inventory, backlog, in-transit pipeline, and a regime-dependent view of neighbours.

The scenarios

The study runs a full factorial of three dimensions — 12 scenarios in total — to see what actually drives amplification:

  • Network topology — linear forward chains vs. closed-loop chains that route recovered material back to the supplier (a circular-economy configuration).
  • Project scope — single project vs. multiple concurrent projects sharing logistics.
  • Information regime — local (neighbours only), global (system-wide state), and efficient (a curated signal shared across tiers).

Demand is grounded in real biweekly steel-procurement data from EU Horizon 2020 building projects. A supply disruption is injected at week 30 — lead times extended for eight weeks — to test how each configuration responds to a shock.

What it found

  • Content over access — the type of signal shared matters more than whether information is shared at all — an efficient, curated signal damped amplification far more than simply exposing all tiers to global state, which often increased it by triggering defensive stockpiling.
  • Topology is contingent — closed-loop chains amplified more than linear ones in single projects, but became a source of resilience once multiple projects shared recovered material.
  • Anticipatory stockpiling — under local visibility, agents built inventory weeks ahead of the week-30 disruption — limited sight lines produced precautionary ordering that amplified supply risk.
  • Validated — agent behaviour reproduced across 10 independent seeds, and matched empirical construction lead-time ranges in 80% of observations against an external UK builders'-merchant dataset.

Method notes

  • Inventory accounting sits outside the agents: agents decide, the simulator settles. Keeping the arithmetic out of the model prevents LLM errors from contaminating the measured variance.
  • Runs repeat across seeds. Because agent decisions are non-deterministic, results are reported as distributions rather than single traces.
  • Agent prompts are versioned with results, since a prompt change is a change to the experimental condition.
