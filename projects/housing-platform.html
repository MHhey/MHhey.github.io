Housing listing and booking platform

Led a six-person team building a React, TypeScript, and Node.js platform with authentication, listings, and real-time booking, delivered across two semesters.

RoleProject lead and full-stack developer
StackReact · TypeScript · Node.js · Prisma · SQLite
WhenMay – December 2025
CodeGitHub repository

Overview

Listing and booking for off-campus student housing were spread across channels that lose state: scattered listings, stale availability, no reliable record of bookings. The platform consolidates listing, search and booking into one system so property state is consistent for every user.

Stack

  • Frontend: React with TypeScript, Tailwind CSS, and Radix UI components
  • Backend: Node.js and Express, with JWT authentication
  • Database: SQLite via Prisma ORM
  • Data and ML: scraped comparable listings and local crime data, used to train a rent price prediction model
  • Testing: Jest and Supertest for the API, Playwright for end-to-end flows
  • Process: Jira, agile, two-semester delivery

Features

  • User authentication
  • Property listings with search
  • Booking system with real-time availability updates
  • Neighborhood safety indicator, built from scraped local crime data
  • Predicted rent pricing, trained on scraped comparable listings and market data for the area

My role

  • Prisma schema for listings, users and bookings
  • Implementation of authentication, listings interface and booking flow
  • Scraped crime data for the safety indicator and comparable-listing data for the price model, and built the price prediction model
